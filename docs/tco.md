# Оцінка вартості пілотного IIoT-проєкту (TCO)

## 1. Мета розрахунку

Оцінити загальну вартість створення та експлуатації системи моніторингу насосної станції протягом одного року.

Для розрахунку прийнято 20 насосних агрегатів із чотирма контрольованими показниками: вібрація, температура, тиск і струм.

Усі суми наведено в доларах США як орієнтовні припущення для навчального проєкту.

## 2. Початкові витрати

| Стаття | Розрахунок | Вартість |
|---|---|---:|
| Edge-пристрої | 20 × $70 | $1400 |
| Датчики та вимірювальні модулі | 20 × $120 | $2400 |
| Серверне обладнання | 1 × $600 | $600 |
| Кабелі та додаткові компоненти | Умовна оцінка | $300 |
| **Разом** | | **$4700** |

## 3. Витрати на впровадження

| Стаття | Розрахунок | Вартість |
|---|---|---:|
| Встановлення обладнання | 40 год × $15 | $600 |
| Налаштування програмного забезпечення | 60 год × $20 | $1200 |
| **Разом** | | **$1800** |

## 4. Річні експлуатаційні витрати

| Стаття | Розрахунок | Вартість |
|---|---|---:|
| Електроенергія | 12 × $15 | $180 |
| Технічне обслуговування | 12 × $40 | $480 |
| Резервне зберігання даних | 12 × $10 | $120 |
| **Разом** | | **$780** |

## 5. Загальна вартість володіння

Початкові витрати — $4700.

Витрати на впровадження — $1800.

Експлуатаційні витрати за рік — $780.

Загальна сума без резерву:

4700 + 1800 + 780 = **$7280**.

Резерв на непередбачені витрати — 10 %:

7280 × 0,10 = **$728**.

Підсумкова оцінка TCO за перший рік:

7280 + 728 = **$8008**.

## 6. Висновок

Орієнтовна вартість впровадження та експлуатації пілотної IIoT-системи для 20 насосних агрегатів протягом першого року становить $8008 з урахуванням резерву на непередбачені витрати. Основна частина витрат пов'язана з придбанням обладнання та початковим налаштуванням. Використання Python, SQLite, Mosquitto та Docker Compose дозволяє створити навчальний прототип на основі відкритого програмного забезпечення без додаткових ліцензійних витрат на ці компоненти.
