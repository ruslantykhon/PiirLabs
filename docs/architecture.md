# Архітектура IIoT-системи моніторингу насосної станції

## 1. Загальна архітектура

Система реалізує збір, передавання, збереження та аналіз телеметрії насосних агрегатів.

До її складу входять:

- Два насосні агрегати, представлені симуляторами PumpSimulator.
- Edge-шлюзи, які передають телеметрію.
- MQTT-брокер Mosquitto.
- Сервіс Ingest для запису даних у SQLite.
- Сервіс Alerts для виявлення аварійних станів.

## 2. MQTT-топіки

Для передавання телеметрії використовується формат:

`plant/{site}/{line}/{device_id}/telemetry`

Для публікації сповіщень:

`plant/{site}/{line}/{device_id}/alerts`

Для повідомлень про стан пристрою:

`plant/{site}/{line}/{device_id}/status`

У поточному розгортанні використовуються майданчик `kyiv`, лінія `line1` та пристрої `pump-01` і `pump-02`.

## 3. Контракт повідомлення

Повідомлення телеметрії містить:

- `device_id` — ідентифікатор пристрою;
- `ts` — часову позначку;
- `running` — стан насоса;
- `metrics` — вібрацію, температуру, тиск і струм.

За ввімкненого підписування повідомлення передається в JSON-конверті з полями `payload`, `ts`, `nonce` та `sig`.

## 4. Збереження даних

Для збереження використовується SQLite.

Таблиця `telemetry` містить сирі вимірювання, а таблиця `telemetry_1m` призначена для хвилинної агрегації.

База даних розміщується в окремому Docker-томі, що дозволяє зберігати інформацію після перезапуску контейнера.

## 5. Виявлення несправностей

Сервіс Alerts використовує правила з порогами, гістерезисом та debounce.

Для вібрації встановлено поріг 4,5 мм/с, гістерезис 0,5 мм/с і debounce 3 вимірювання.

Після виникнення несправності генерується подія `raised`, а після нормалізації показника — `cleared`.

## 6. Надійність

Для підтримання працездатності використовуються повторні спроби підключення, буферизація повідомлень у шлюзі, Docker healthcheck та політика перезапуску `unless-stopped`.

Поточна реалізація є навчальним прототипом. Вона не забезпечує гарантованої доставки кожного повідомлення за будь-яких умов, оскільки використовується буфер у пам'яті та обмеження часу дії підписаних повідомлень.
